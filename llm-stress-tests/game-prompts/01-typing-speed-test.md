# Test 1: Gamified Typing Speed Test (Falling Words)

Create a complete, fully functional, single-file HTML application for a gamified typing test. Include all HTML, inline CSS, and JavaScript in this single file. Do not use external CSS/JS libraries or placeholders/TODO comments.

Requirements:
1. Gameplay Mechanics: Words fall from the top of a designated container toward the bottom. The player types in a text input field at the bottom. When a typed word matches a falling word, press Enter (or auto-clear) to destroy the word and score points.
2. Analytics: Continuously calculate and display real-time Words Per Minute (WPM) and Accuracy Percentage.
3. Progression: As the score increases, slightly increase the word fall speed and spawn frequency.
4. Persistence: Implement a "High Score" system saved in the browser's localStorage that updates when a game ends.
5. Visuals & UX: Clean, modern dark-mode styling with smooth CSS transitions, visually distinct words, and clear Game Over/Restart screens.
