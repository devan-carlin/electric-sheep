# Test 3: "2048" Matrix Shifting & State Engine

Create a single, complete HTML file containing all HTML, CSS, and JavaScript for a fully playable 2048 game. Do not use external frameworks, libraries, or placeholder comments.

Requirements:
1. Matrix Engine: Maintain a 4x4 grid array in JavaScript handling directional shifts (Up, Down, Left, Right via Arrow keys or WASD).
2. Game Rules: 
   - Sliding tiles shift as far as possible in the input direction.
   - Identical adjacent tiles merge once per shift step into their combined value (e.g., two 2s become a 4).
   - Spawn a new tile (90% chance of '2', 10% chance of '4') in a random empty cell only after a valid board move occurs.
3. Game Over Condition: Accurately detect Game Over ONLY when the grid is completely full AND no valid adjacent merges are possible in any direction.
4. UI & Styling: CSS Grid layout with smooth tile transitions, dynamic background colors for higher tile values (2, 4, 8, 16, 32, 64, 128, 256, 512, 1024, 2048), a live score tracker, and a reset button.
