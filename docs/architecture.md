# Electric Sheep — Overview

## What this is

Not a single project or product. A collection of independent workspaces
for testing inference on the 4x Intel Arc Pro B70 AI server:

- **[LIVE] serving** — the only persistent part: a 4-GPU service stack
  (2x ComfyUI + 2x llama.cpp chat endpoints), managed by `serve/`.
- **[RUNTIME] runtimes** — vLLM and llama.cpp builds + env configs, set
  up by `build/` and shared by everything else.
- **[EXPERIMENT] experiments** — model A/B tests, throughput/stability
  matrices, quantization work, stress tests. Each is self-contained;
  results live in the directory that produced them.
- **[DOCS] docs + articles** — write-ups of what was tested and what worked.

There is no shared codebase and no build that spans directories. If a
directory is not part of the live stack, it is an experiment or a tool
and may be stale. The live stack is documented in `serve/SERVICES.md`
(what/why) and `serve/HANDOFF.md` (how to call + manage).

## Live stack (the only persistent part)

One service per GPU, all managed by `serve/start-all.sh`:

| GPU | Service | Port | Notes |
|-----|---------|------|-------|
| 0 | ComfyUI A | 8188 | image generation |
| 1 | ComfyUI B | 8189 | image generation |
| 2 | llama.cpp `qwen` | 8088 | Qwen3.6-35B-A3B Aggressive (MoE), 256K ctx |
| 3 | llama.cpp `gemma` | 8089 | Gemma4 26B-A4B Balanced, 256K ctx |

- 8088/8089 speak the OpenAI API (no auth); Docker `open-webui` is the
  human-facing chat UI.
- Served names are version-agnostic (`qwen`, `gemma`); the weights behind
  them can be swapped without touching clients.

Everything else in this repo exists to test, benchmark, or improve what
runs on these GPUs.

## Backend rules

Per-backend rules, shared by the live stack and the experiments.

### vLLM

- **Target device:** `VLLM_TARGET_DEVICE=xpu`
- **Tensor parallelism:** `--tensor-parallel-size 4` (or `2` for dual-model)
- **GPU memory utilization:** `0.80` (conservative ceiling)
- **KV cache dtype:** `fp8`
- **Python version:** 3.12

### llama.cpp SYCL

- **Environment:** `source ~/electric-sheep/llama/set-env.sh` (loads oneAPI + SYCL tuning)
- **GPU selector argument:** `set-env.sh 0,1` for GPUs 0+1, `set-env.sh 0` for GPU 0 only
- **Layer split mode:** `-sm layer` for multi-GPU (most stable on SYCL)
- **Flash attention:** Use `--flash-attn auto`
