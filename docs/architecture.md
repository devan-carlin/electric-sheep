### AI Server (Ubuntu — Intel Arc B70)

| Component | Spec |
|-----------|------|
| OS | Ubuntu 26.04 LTS (Kernel 7.0.0-29) |

| Component | Spec |
|-----------|------|

| Path | Purpose |
|------|---------|
| `~/electric-sheep/vllm/.venv/` | vLLM Python 3.12 virtual environment |
| `~/electric-sheep/vllm/vllm-src/` | vLLM source code |
| `~/electric-sheep/llama/llama.cpp/` | llama.cpp source code |
| `~/electric-sheep/llama/llama.cpp/build/` | llama.cpp build output |
| `~/electric-sheep/models/` | Shared model storage (vLLM + llama.cpp) |

## vLLM Deployment Rules

- **Target device:** `VLLM_TARGET_DEVICE=xpu`
- **Tensor parallelism:** `--tensor-parallel-size 4` (or `2` for dual-model)
- **GPU memory utilization:** `0.80` (conservative ceiling)
- **KV cache dtype:** `fp8`
- **Python version:** 3.12

## llama.cpp SYCL Rules

- **Environment:** `source ~/electric-sheep/llama/set-env.sh` (loads oneAPI + SYCL tuning)
- **GPU selector argument:** `set-env.sh 0,1` for GPUs 0+1, `set-env.sh 0` for GPU 0 only
- **Layer split mode:** `-sm layer` for multi-GPU (most stable on SYCL)
- **Flash attention:** Use `--flash-attn auto`
